# Contributing to Books API

Thank you for your interest in contributing to our Books API project! We're excited to have you help us improve this project.

## How to Contribute

### Reporting Issues

If you find a bug or have a suggestion for improvement, please open an issue on GitHub with:

- A clear title and description
- Steps to reproduce (for bugs)
- Expected vs actual behavior
- Your environment (OS, Bun version, etc.)

### Making Changes

1. **Fork the repository**

   ```bash
   git clone https://github.com/yourusername/books-api.git
   cd books-api
   ```

2. **Create a feature branch**

   ```bash
   git checkout -b feature/your-feature-name
   ```

3. **Install dependencies and start development**

   ```bash
   bun install
   bun run dev
   ```

4. **Make your changes**
   - Follow the existing code style
   - Write clear, descriptive commit messages
   - Test your changes thoroughly

5. **Push and create a Pull Request**
   ```bash
   git push origin feature/your-feature-name
   ```
   - Provide a clear description of your changes
   - Reference any related issues

## Development Guidelines

- **Code Style**: Follow existing patterns in the codebase
- **TypeScript**: Use strict types, avoid `any` where possible
- **Database**: Make sure to handle SQL parameters safely
- **Testing**: Test your changes before submitting

## Areas for Contribution

- 🐛 Bug fixes
- ✨ New features (authentication, pagination, filtering, etc.)
- 📚 Documentation improvements
- 🧪 Tests and test coverage
- 🔒 Security improvements
- ⚡ Performance optimizations

## Code of Conduct

Please be respectful and constructive in all interactions. We're building this project together!

## Questions?

If you have questions, feel free to open a discussion or issue on GitHub.

Happy coding! 🚀
